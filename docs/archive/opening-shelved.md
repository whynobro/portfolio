## As it was documented in CLAUDE.md

### The opening

`src/intro.ts`: a ~22 s montage under a night sky, paced by one `PACE`
constant. Putter (drawing with real dimensions, stock, cut along the REAL
toolpath with the live operation and tool captioned), WERC docking, Ramps
(photo mosaic, then $39,600 headline + product + chameleonramps.com capture),
wave rack-and-pinion, bot alert-to-order (labelled illustrative), then the
finale wall and the name handing off to the page heading (baseline-aligned).
Hand-off mock-ups: dawn (default) or night (`?hero=night`, night entrance in
chrome.css); undecided. The head script gates it: landing route only, once
per session, never with `?shots=1` or reduced motion; a 26 s fallback
uncovers the page if the module never runs (raise it if the montage grows).
Any click, key, scroll or Skip ends it.

The toolpath is `src/scenes/putter/toolpath.ts`, generated by
`node scripts/prep-toolpath.mjs` from `assets-src/putter/putter-op1.nc`
(Haas TM-1P; G-code X along the length, Y mirrored, Z height; chosen by
overlaying the finishing pass on the STL). Previews:
`node scripts/make-intro-video.mjs [out.mp4] [w] [h]` (`URL=...?hero=night`).

## index.html (head script, inline style, cover markup)

```html
    <script>
      // Before first paint: screenshot mode, and whether the opening plays.
      // It plays only on the landing route, once per browser session, never
      // in screenshot mode and never with reduced motion. A 26 s fallback timer
      // uncovers the page even if the intro's module never runs.
      (function () {
        var el = document.documentElement;
        var q = new URLSearchParams(location.search);
        var shots = q.get("shots") === "1";
        if (shots) el.dataset.shots = "1";
        // Hand-off mock-up being decided: ?hero=night dresses the entrance as
        // night so the intro lifts onto the same sky. Default: dawn.
        if (q.get("hero") === "night") el.dataset.hero = "night";
        try {
          var landing = location.hash === "" || location.hash === "#/";
          var still = matchMedia("(prefers-reduced-motion: reduce)").matches;
          if (!shots && landing && !still && !sessionStorage.getItem("intro")) {
            sessionStorage.setItem("intro", "1");
            el.dataset.intro = "play";
            setTimeout(function () {
              delete el.dataset.intro;
            }, 26000);
          }
        } catch (e) {
          /* storage blocked: no intro, the page simply shows */
        }
      })();
    </script>
    <style>
      /* Inline so the cover is up before the stylesheet loads. */
      #intro { display: none; }
      html[data-intro="play"] { overflow: hidden; }
      html[data-intro="play"] #intro {
        display: block; position: fixed; inset: 0; z-index: 1000; background: #04060b;
        transition: opacity 0.45s ease;
      }
      #intro.intro--out { opacity: 0; pointer-events: none; }
    </style>
  </head>
  <body>
    <a class="skip-link" href="#main">Skip to content</a>

    <!-- The opening (src/intro.ts): the putter from drawing to part under a
         night sky. Shown only when the head script set data-intro="play". -->
    <div id="intro">
      <canvas aria-hidden="true"></canvas>
      <p class="intro__label mono" aria-hidden="true"></p>
      <button class="intro__skip" type="button">Skip intro</button>
    </div>
```
